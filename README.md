# 별맥 MVP

별자리(네이탈 차트) + 취향/상황을 이용해 두 가지 맥주를 추천하는 정적 웹앱 MVP입니다.

## 실행
- `index.html`을 브라우저로 열거나 정적 서버에서 실행합니다.
- Cloudflare Pages에는 폴더 전체를 업로드하면 됩니다.

## 추천 규칙
- 내 입맛 PICK: 9문항의 취향/상황만 사용
- 별이 고른 PICK: 취향·상황 45% + 네이탈 55%
- 네이탈 추천은 취향·상황 적합도 60점 미만 맥주를 제외

## 개인정보
출생정보와 질문 응답은 브라우저 메모리에서만 계산하며 저장하거나 서버로 전송하지 않습니다.

## MVP 네이탈 계산
태양·달·금성·화성·상승궁을 브라우저에서 저정밀 천문 공식으로 계산합니다. 별자리 추천 엔터테인먼트용으로는 충분하지만 전문 천문/점성 소프트웨어를 대체하지 않습니다.
